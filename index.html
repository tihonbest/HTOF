На что обратить внимание

Небольшие подсказки, которые пригодятся на проверочной.

ОДЗ — область допустимых значений

У дроби знаменатель никогда не должен быть равен нулю. Сначала найди запрещённые значения, и только потом упрощай выражение.

Сокращение дроби

Если общий множитель сокращается, это не возвращает запрещённое значение в область определения исходной функции.

💡 На проверочной записывай не только ответ, но и переходы: учителю важно видеть ход рассуждений.

Запомни:

b сдвигает график по горизонтали, k — по вертикали. Минус перед функцией отражает график относительно оси X.

Шпаргалка перед проверочной

Самое важное, что стоит помнить.

01

ОДЗ дроби

Знаменатель не равен нулю. Реши уравнение со знаменателем, найди корни и исключи их.

A(x)/B(x), B(x) ≠ 0
02

Разложение

Ищи общий множитель. Например, вынеси x за скобки.

x² + 5x = x(x + 5)
03

Сдвиг графика

f(x − a) — вправо на a; f(x + a) — влево на a. Внешнее +b — вверх.

y = f(x − a) + b
04

Основные графики

Прямая, парабола, модуль, гипербола, корень и кубическая функция.

x · x² · |x| · 1/x · √x · x³
05

Кусочная функция

Каждая формула работает только на своём промежутке. Смотри на знаки ≥, ≤, > и <.

f(x) = { f₁(x), x ≥ a; f₂(x), x < a }
06

Выколотая точка

После сокращения дроби запрещённые значения исходного выражения остаются исключёнными.

1/x, x ≠ 0
